## 构建与验证

运行 dotnet build Launcher.sln、dotnet test Launcher.sln 和兼容测试项目，再执行 build/package-94-patch1.ps1。

build/test-94-patch1.ps1 从已发布 v26A17094-patch 标签提取更新检测、下载和安全校验代码，在隔离目录里分别以原 94 现代版与兼容版为基础进行真实下载流、更新 EXE 启动、替换、启动确认与回读校验。验证游戏、账户、设置保留、错误基础版本被拒绝及已安装补丁不重复提示。

隔离测试在当前 Windows 上执行；Windows 7 实机效果未验证。补丁包含两种运行时的完整主程序，不是二进制差分包。

产物、日志与界面渲染图统一放在项目交付文件目录。本次 UI 恢复原 91 的 ProjectListStep 布局，深浅主题都需检查顶部与底部过渡。
