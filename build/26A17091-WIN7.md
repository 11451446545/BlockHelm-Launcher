# 26A17091 双版本统一安装包

基线为原版标签 `v26A17091`（`019754c`），分支 `compat/26A17091-win7`。
同一个 x64 安装程序自动选择：

| 系统 | 安装的版本 | 自包含运行库 |
| --- | --- | --- |
| Windows 7 SP1 / 8 / 8.1 x64 | `26A17091-Compatible` | .NET / Windows Desktop 6.0.36 |
| Windows 10 / 11 x64 | `26A17091` | .NET / Windows Desktop 8.0.29 |

两版仍使用原 WPF 界面，没有 Qt。数字版本均为 `0.9.16.0`；兼容后缀不提高更新序号。
本次发布独立统一安装器，不修改正式版或测试版更新清单。
旧 91 因版本序号相同不会自动提示更新，请下载安装器覆盖安装。
不得把此 Setup 配置成原自更新流程直接替换的主程序 EXE。

## 保留原版设计

`build/verify-91-design.ps1` 比较原标签中 309 个界面、样式、资源、图标、
着色器、动画、控件与行为文件，只允许明确列出的 5 个文字可读性文件变化，
另允许 1 个主题服务文件修复切换逻辑，其余 303 个要求 Git 内容哈希一致。
游戏下载、资源列表及页面标题/状态文字增加玻璃背景专用高对比前景和柔和暗影；
输入框保持原主题色。原 91 布局、动画、高斯背景、玻璃和鼠标光效保持原样。
兼容改动另包含 .NET 6 编译、旧系统 API 对接、缺失字体回退与安装前置条件。
主题菜单使用独立的 Dark/Light 标识，主题应用和设置持久化均保留手动选择；
修复默认主题为浅色时，深色选项失效及重启后恢复浅色的问题。
下载、实例、账户、联机、资源中心和更新入口均保留。

字体回退只在系统缺少 Microsoft YaHei UI / Segoe MDL2 Assets 时生效。
本地字体资源不纳入 Git；微软字体的分发权限不由项目 GPL 授予，见
`COMPATIBILITY-NOTICES.txt`。

## 安装目标

- Windows 7 SP1 x64 及更新的 x64 Windows；不包含 32 位版本。
- 自动选择自包含 .NET / Windows Desktop 6.0.36 或 8.0.29，不需要用户另外安装 .NET。
- 安装包内置原始签名的 VC++ 2015–2019 x64 和 Win7 KB3063858。
- 仅在 Win7 的 TLS 1.2 客户端注册表值缺失时添加启用设置；已有设置保留。
- 高斯桌面背景在 Win7 使用 DWM Aero BlurBehind，需要 Aero 桌面合成和合适的显卡驱动。
  着色器、鼠标光效和动画保持原版代码，不主动禁用。
- 设置、日志和默认游戏目录与原版一样，位于 EXE 旁的 `BHL` / `.minecraft`。
  新安装默认使用可写的 `%LOCALAPPDATA%\Programs\BlockHelm Launcher`；覆盖安装沿用原路径。
  手动选择的安装目录也必须允许运行账户写入。账户仍通过原版账户路径规则存储。
  安装程序不删除游戏、设置或账户。
- 单文件仅解压原生库，禁止 `IncludeAllContentForSelfExtract=true`，
  否则 .NET 会将 `AppContext.BaseDirectory` 指向临时缓存，破坏原版数据目录行为。

## 重现构建与检查

在仓库根使用 PowerShell 7 和 .NET SDK 8，安装 Inno Setup 6：

```powershell
dotnet test Launcher.sln -c Release
dotnet test Launcher.CompatibilityTests/Launcher.CompatibilityTests.csproj -c Release
./build/verify-91-design.ps1
./build/package-91-universal.ps1
./build/test-91-installer.ps1
./build/smoke-91-launchers.ps1
```

字体位于本地 `Launcher.App/Compatibility/Fonts/`，文件为
`msyh.ttc`、`msyhbd.ttc`、`msyhl.ttc`、`segmdl2.ttf`。
如需复现本机的微软登录或第三方资源服务配置，继续使用原版配置方式；
不要把私人配置、账户或访问令牌加入源码。

安装包默认输出到项目 `交付文件/26A17091统一安装包`，旁附 SHA-256 校验文件。历史桌面产物已移至该目录。
`-SkipPublish` 可复用已校验的两版 EXE 重新编译安装器。
安装验证脚本使用编译期隔离模式：不注册卸载、不建快捷方式、不修改系统注册表、
不运行前置安装；分别校验两个实际安装分支的文件哈希及系统选择矩阵。
正式安装器不包含强制选择分支的测试参数。

## 当前验证与边界（2026-10-02）

- 原版回归测试 458 项通过；.NET 6 自包含兼容测试 11 项通过，包含同一组主题切换与保存回归用例。
- 303 个原版设计文件哈希一致，5 个文字可读性文件及 1 个主题切换逻辑文件改变。
- 两框架、深浅两主题的真实 WPF 列表控件在亮暗背景上完成离屏渲染检查。
- 安装验证覆盖 6.1/6.2/6.3/10.0 系统选择矩阵及两个实际安装分支的文件哈希。
- 本机 Win11 验证两版发布后的单文件 EXE 启动与窗口响应。
- 已确认读取 EXE 旁的测试设置；日志和游戏目录不再落入运行库解压缓存。
- 官方 Minecraft 版本列表请求返回 HTTP 200，拉取 917 个版本。
- 初次更新检查遇到网络超时；随后用 .NET 6.0.36 原更新服务复测成功，
  正式版返回“无新版本”，远程清单为 `26A17091`。对照 .NET 8.0.29 同样成功。
  本次没有执行下载安装更新或修改线上清单，不能将握手验证等同于完整更新验证。
- 未发现可用的 Win7 实机或虚拟机，所以 Win7 安装、Aero 显示、驱动相关效果、
  登录、联机和完整游戏启动仍需在目标系统验证。源码一致不等于跨系统像素级效果已实测一致。
- .NET 6 与 Win7 都已结束厂商支持；这个本地兼容构建不代表恢复厂商支持。
