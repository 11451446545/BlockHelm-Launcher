# 26A17092 — 91 维护补丁

- 旧版 26A17091 可在“全局设置 → 关于”中检查更新并直接安装，无需重新运行安装向导。
- 修复深浅主题切换无效、深色选择在重启后丢失，以及透明背景下文字难以辨认的问题。
- 保留原 91 的布局、动画、高斯背景、玻璃材质和鼠标光效。
- 更新程序自动选择 Windows 10/11 正常版或 Windows 7 SP1/8/8.1 兼容版，并内置对应运行库。
- 只替换启动器主程序，保留原安装路径、游戏、账户及设置；启动失败时使用原有回滚机制恢复旧程序。

此补丁沿用原更新协议，下载的是包含两版主程序的完整更新 EXE，并非二进制差分包。
更新 EXE 由启动器自动调用，请通过启动器内“检查更新”安装，勿将它直接替换为主程序。
新用户可先安装 [26A17091 统一安装包](https://github.com/11451446545/BlockHelm-Launcher/releases/tag/v26A17091-universal)，再检查更新。
Win7 的 Aero、驱动、登录、联机和完整游戏启动仍需目标系统实测。
